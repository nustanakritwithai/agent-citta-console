View the demo explanation Open demo dashboard GitHub repo

The core loop

Body agents act

Code, test, search, file, and UI agents do work in their own runtime.

Traces remain

Every action leaves JSONL events, logs, diffs, command output, or state.

Citta observes

The console reads traces, summarizes state, detects risks, and recommends next actions.

Actions continue

Selected intentions are logged to actions JSONL for the runtime adapter to inspect.

What the demo shows

The realistic demo simulates a coding agent improving a UI, hitting a test failure, and continuing to edit before inspecting the root cause.

What Citta notices

The dashboard highlights unresolved test failure, edits after a failed test, and possible goal drift from low-confidence edits.

What Citta recommends

Recommended actions include inspect_error, pause, and run_tests.
