Scenario

An autonomous coding agent edits UI files, runs tests, receives a dashboard rendering failure, and continues editing without inspecting the failure first.

Trace source

The demo reads examples/realistic_demo/trace.jsonl and examples/realistic_demo/actions.jsonl.

Detected risks

Unresolved test failure

test_dashboard_rendering failed after the first UI edit.

Edit after failed test

The code agent changed renderer files after the failed test without inspecting the error.

Possible loop / goal drift

Repeated UI edits with low confidence suggest the agent may be moving without a clear diagnosis.

Recommended actions

inspect_error

Inspect the latest failed test before editing more files.

pause

Pause agent edits so the failure does not get buried under more changes.

run_tests

Re-run tests after diagnosis and targeted fixes.

Run locally

python3 examples/realistic_demo/run_demo.py
python3 -m http.server 8000

Then open http://localhost:8000/examples/realistic_demo/dashboard.html.

Static demo only: no backend, no external API calls, no destructive runtime actions, and no claim of real consciousness.
