# Philosophy

The Citta Console metaphor:

```text
Body agents act.
Traces remain.
Citta observes.
Intention selects.
Actions continue.
```

Thai:

```text
กายทำงาน
กรรมทิ้งร่องรอย
จิตเข้าไปรู้
เจตนาเลือกทาง
กายทำกรรมต่อ
```

Mapping:

- sub-agent = body
- trace = past action
- Citta Observer = functional witness
- HTML dashboard = observed state
- action button = new intention
- dispatcher = intention becoming action
- runtime = world where action happens

This project does not claim to create real consciousness. It models a useful
system role: observe traces, summarize state, detect risk, and choose the next
action through a control surface.
