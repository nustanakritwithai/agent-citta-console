# Concept

`agent-citta-console` is a universal HTML control panel for agent awareness and
action chaining.

The project treats sub-agents as body agents: they edit files, run commands,
search, test, or deploy. They do not need to describe themselves. They only need
to leave trace events in a common JSONL format.

Citta Console reads those traces, infers state, detects risks, recommends next
actions, and renders an HTML dashboard with action buttons.

This is a functional witness layer, not a claim of real consciousness.
